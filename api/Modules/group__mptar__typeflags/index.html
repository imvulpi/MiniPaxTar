MPTAR_CONTINOUS_FILE '7' Contiguous file.
MPTAR_PAX_EX_HEADER 'x' PAX extended header for the next file.
MPTAR_PAX_GLOBAL_EX_HEADER 'g' PAX global extended header for all following files.

Enumeration of tar header typeflag values.

Provides strongly-typed constants corresponding to the MPTAR_TYPE_* macro definitions. Regular files can be encoded as either MPTAR_TYPE_FILE ('0') or MPTAR_TYPE_FILE_LEGACY ('\0'); parsers should check for both types when identifying standard files.
