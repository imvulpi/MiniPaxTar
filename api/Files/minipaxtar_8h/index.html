Functions Documentation

function mptar_strlen

mptar_size_t mptar_strlen(
    const char * str
)

Computes the length of a null-terminated string safely.

Parameters:

  • str Pointer to the null-terminated string.

Return: The number of characters preceding the terminating null byte, or 0 if str is MPTAR_NULL.

Note: This function can be overridden by defining mptar_strlen.

function mptar_strnlen

mptar_size_t mptar_strnlen(
    const char * str,
    mptar_size_t max_limit
)

Computes the length of a string up to a maximum limit safely.

Parameters:

  • str Pointer to the string.
  • max_limit Maximum number of bytes to inspect.

Return: The number of characters preceding the terminating null byte or max_limit, whichever comes first, or 0 if str is MPTAR_NULL.

Note: This function can be overridden by defining mptar_strnlen.

function mptar_memcmp

int mptar_memcmp(
    const void * s1,
    const void * s2,
    mptar_size_t size
)

Compares two blocks of memory.

Parameters:

  • s1 Pointer to the first memory block.
  • s2 Pointer to the second memory block.
  • size Number of bytes to compare.

Return: 0 if the blocks match, a negative value if s1 is less than s2, or a positive value if s1 is greater than s2.

Note: This function can be overridden by defining mptar_memcmp.
